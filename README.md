Ingeniero de Sistemas · Infraestructura, Seguridad & Automatización Operativa  
📍 Huacho, Lima – Perú  

- **Proyecto principal:** PMS (Property Management System) para el sector hotelero mediante arquitectura .NET (C#, ASP.NET Core, EF Core).
- **Seguridad e Infraestructura:** Diseño de planes de contingencia (Disaster Recovery) con réplica automatizada en la nube (OneDrive Cloud API), políticas de control de accesos basados en el principio de menor privilegio (PoLP) y mitigación de riesgos locales (Permisos NTFS / BitLocker).
- **Automatización Operativa (RPA):** Desarrollo de flujos híbridos y scripts de automatización asistida con Playwright y Python para la optimización y consistencia en la carga masiva de reportes regulatorios externos (SUNAT / MINCETUR).
- **Entornos de Soporte L2:** Gestión de laboratorios locales para administración de identidades, directivas de grupo (GPOs), redes locales (TCP/IP, DNS, DHCP) y soporte remoto securizado.
- **Interés actual:** Administración de Servidores (SysAdmin), ciberseguridad, redes corporativas y marcos de gestión de servicios de TI (ITIL®).
